Conectar con GitHub

Para publicar cambios desde esta página hace falta un token de GitHub. Se crea una sola vez:

  1. Abre github.com/settings/personal-access-tokens/new.
  2. En «Repository access» elige Only select repositories y marca catalogo-3d.
  3. En «Permissions → Repository permissions» pon Contents: Read and write.
  4. Genera el token, cópialo (empieza con github_pat_) y pégalo aquí.

Se guarda solo en este navegador. No lo compartas.
